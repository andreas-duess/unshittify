Logitech announced in January 2024 that it would close mysqueezebox.com, the service Squeezebox players used for streaming and setup. The community had already taken over Logitech Media Server and renamed it Lyrion. Version 8.4, in February 2024, removed every MySqueezebox dependency, so streaming services run as plugins on your own server and the players keep playing.
